## Trait Echo v1 environmental use

On 2026-07-12, the project owner also requested strategic use of fRiENDSiES
flowers, sprouts, and hand items in Thornvale's environment. Trait Echo v1
reuses `hand-flower-white.glb` for three strategic placements: one private
arrival offering and a paired set of witnesses at the Community Ledger. At
runtime, the rigid frame-zero pose is normalized in memory and rendered as one
three-instance mesh; no derived binary is written or added to the build.

Flower White has one semantic job: offered and witnessed kindness. When this
family loads, it replaces the 56 generic procedural flowers on the central
route; the distant perimeter meadow remains and the full procedural meadow is
restored if the family fails. The Ledger witness pair changes scale and posture
with story state, including the impossible bell, false record, and comply/alter
response.
A shared code-native civic mount grounds all seven Trait Echo placements but is
not a fRiENDSiES asset. This arrangement is a Thornvale-authored environmental
adaptation, not a canonical token or a new fRiENDSiES trait. `?traits=off`
removes the environmental treatment without changing the `#6602` player.

This authorization covers only the exact runtime hash above and the documented
three-instance Thornvale arrangement. It does not approve other `#0001` files,
other traits, arbitrary token streaming, or standalone redistribution. The
separate remote-player authorization in ADR 0003 does not broaden this local-
file or environmental grant.
