# Thornvale town cottages source

## Ownership and provenance

These four cottage models were authored procedurally for Thornvale in Blender.
They do not contain third-party meshes, textures, fonts, HDRIs, or other external
art inputs. Their palette follows the in-project `TOWN_PALETTE` values.

- Creator: Thornvale project, generated by `scripts/build-town-cottages.py`
- First generated: 2026-07-12
- Source license: the same terms as the Thornvale repository
- External redistribution constraints: none beyond the repository's own terms
- Deterministic seed: `713`
- Blender baseline: Blender 4.5.9 LTS

## Editable source

`thornvale-cottages.blend` contains four named empty roots staged apart for easy
inspection:

| Root | Authored wall footprint | Wall height | Source stage position |
| --- | --- | --- | --- |
| `Cottage_berry_bakery` | 6.0m x 4.5m | 3.2m | `(-11, -8, 0)` |
| `Cottage_lavender_library` | 5.0m x 6.0m | 4.0m | `(11, -8, 0)` |
| `Cottage_mint_tea_house` | 4.0m x 4.0m | 2.8m | `(-11, 8, 0)` |
| `Cottage_rose_post_office` | 6.0m x 5.0m | 3.6m | `(11, 8, 0)` |

Blender is Z-up. Cottage façades face Blender `-Y`, which the glTF exporter
converts to runtime `+Z`. One Blender unit equals one meter. Detail such as
eaves, porches, signs, and trellises deliberately extends beyond the authored
wall footprint.

Roof cross-sections are closed solids with outward face winding. The tea-house
curled eaves use a simple perimeter with a shallow underside below the wall cap;
Blender loop triangulation handles the concave silhouette before the material
meshes are merged. This prevents the crossed fan triangles and mixed cap winding
that produced the former stretched/flickering roof planes. The veranda canopy
keeps a modeled gap from the main roof while clearing the door lintel and
remaining seated on its posts. Merged triangles are sorted before Blender derives
smooth normals, then index-canonicalized after export, so clean processes produce
the same runtime bytes.

## Rebuild

From the repository root:

```bash
/Applications/Blender-4.5-LTS.app/Contents/MacOS/Blender \
  --background --factory-startup \
  --python scripts/build-town-cottages.py -- \
  --source assets-src/town-cottages/thornvale-cottages.blend \
  --output public/town/cottages/thornvale-cottages.glb
```

Validate the exported hierarchy and budgets through a clean glTF re-import:

```bash
/Applications/Blender-4.5-LTS.app/Contents/MacOS/Blender \
  --background --factory-startup \
  --python scripts/build-town-cottages.py -- \
  --validate-only public/town/cottages/thornvale-cottages.glb
```

The generator saves the source while roots are staged, then temporarily resets
all four roots to the origin for export. Runtime code can therefore clone a
named top-level root and place it directly at a town-layout coordinate with unit
scale.
