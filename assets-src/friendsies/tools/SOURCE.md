Exact intake command:

```bash
curl --fail --location \
  https://storage.googleapis.com/friendsies-v2-assets-d8088d/assets/2e7d86ace19eafc64df6be34dbd82483.glb \
  --output public/friendsies/tools/axe-v1.glb
```

Revalidate identity and the metadata-only GLB contract with:

```bash
wc -c public/friendsies/tools/axe-v1.glb
shasum -a 256 public/friendsies/tools/axe-v1.glb
npm run friendsies:probe -- --type hand --value Axe --dry-run
```

The probe classifies the GLB as a `rigid-candidate`. Axe v1 does not remove the
armature or bake a static frame-zero mesh: `StewardshipWorld` retains the
canonical skinned hierarchy under a Thornvale-owned action anchor. A future
static bake would require decoded proof that every rendered vertex is rigidly
attached to one joint before changing that runtime contract.
